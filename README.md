# Система управления отпусками 2026

Это статическое веб‑приложение (HTML/CSS/JS).

## Запуск "как файл" (file://)

Откройте `index.html` двойным кликом.

### Почему раньше была ошибка CORS

Раньше `index.html` подключал JS как ES‑модуль:

- `<script type="module" src="js/app.js"></script>`

При открытии по `file://` многие браузеры присваивают странице origin `null` и **блокируют загрузку модулей** (в консоли это выглядит как CORS‑ошибка). Поэтому теперь скрипт подключается как обычный:

- `<script src="js/app.js"></script>`

## Запуск через локальный сервер (опционально, если когда‑нибудь понадобится)

Если в будущем появится `fetch()`/импорт внешних модулей, удобнее запускать через `http://localhost`.

- Node: `npx --yes http-server -p 5173`
